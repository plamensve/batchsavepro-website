How can we help?

Find quick troubleshooting steps for downloads, Gmail attachments, PDF Tools, account access and subscription management.

Downloads

If a file is not detected, reload the page, reopen BatchSave Pro and run the scan again. Some websites use protected or temporary download links that browsers cannot fetch directly.

Gmail attachments

Open the Gmail conversation containing the attachments, make sure the attachment cards are visible, then scan the open message with BatchSave Pro.

PDF Tools

Images → PDF, Merge PDF and Compress PDF process selected files locally in Chrome. If a file fails, try reopening the extension and selecting the source file again.

Account access

Use the reset password option in the extension if you cannot sign in. Password recovery links are sent to the email address associated with your BatchSave Pro account.

Before reporting an issue

  • Update Chrome to the latest available version.
  • Reload BatchSave Pro from chrome://extensions.
  • Retry the action on the original page or Gmail conversation.
  • Include the extension version, Chrome version and a short description of what happened.
