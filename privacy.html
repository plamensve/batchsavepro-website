Privacy Policy

Built to minimize unnecessary data movement.

This policy explains how BatchSave Pro handles account information, page resources, Gmail access, local PDF processing and subscription-related data.

Last updated: November 9, 2026. BatchSave Pro is being prepared for public distribution through the Chrome Web Store. This policy reflects the current extension architecture.

1. What BatchSave Pro does

BatchSave Pro is a Chrome extension for discovering and downloading files and images from web pages, handling selected Gmail attachments, and performing local PDF operations such as image-to-PDF conversion, PDF merging and structural PDF optimization.

2. Page scanning and downloads

When you choose to scan a page, BatchSave analyzes resources available to the extension on that page so it can identify downloadable files and images. Scan results are displayed inside the extension. Supported download packaging and ZIP generation are performed locally in Chrome.

BatchSave does not intentionally overwrite existing files. Chrome may automatically create a unique filename when a matching file already exists.

3. PDF Tools

Files selected for Images → PDF, Merge PDF and Compress PDF are processed locally in the browser. These PDF Tool inputs are not uploaded to BatchSave Pro servers merely to perform the document operation.

4. Gmail access

BatchSave provides Gmail attachment functionality only when you initiate it. The extension may use visible Gmail attachment controls for an open message and, when configured and authorized, the official Gmail API for mailbox attachment search and retrieval.

  • Google authorization is explicit.
  • The requested Gmail API access is read-only.
  • Gmail attachment data is used to perform the attachment workflow you request.
  • BatchSave does not use Gmail message data for advertising.

5. Account information

BatchSave uses Supabase for user authentication, email verification, password recovery, account identity and entitlement checks. Account information may include your email address, name, authentication identifiers and access/subscription state.

6. Subscription and billing

Subscription checkout and billing management use Stripe. Payment card details are handled by Stripe’s checkout and billing systems rather than being stored directly by the browser extension.

7. Authentication emails

Account confirmation and password recovery emails are sent using the configured Supabase authentication email flow and the BatchSave Pro email delivery provider.

8. Local extension storage

The extension may use Chrome extension storage to maintain session information, short-lived workflow state, preferences and operational state required for features such as authentication and downloads.

9. Permissions

BatchSave requests browser permissions needed for its core functions, including active-tab access, downloads, extension storage, scripting on pages you choose to scan, identity for Google authorization, and access to the BatchSave account backend. Optional website access is requested when necessary to retrieve selected page resources.

10. Third-party services

BatchSave currently relies on service providers for specific functions, including Supabase for account infrastructure, Stripe for subscription billing, Google for Gmail authorization/API access, and Resend for transactional email delivery.

11. Security and limitations

No software can guarantee that every website resource can be downloaded. Some sites require authentication, block cross-origin requests, use expiring links or dynamically generate files. BatchSave does not bypass website access controls or disabled Gmail downloads.

12. Changes to this policy

This policy may be updated as BatchSave Pro evolves, particularly before or after Chrome Web Store publication or when connected services change. The current version will be published on this page.

13. Contact

Support and contact information will be added to the official BatchSave Pro website before the public Chrome Web Store release.
