Gmail attachments

Your email attachments, without the repetitive clicking.

BatchSave Pro supports two Gmail workflows: quick scanning of visible attachment cards in an open Gmail message and a full attachment manager using the official Gmail API after Google authorization.

01
Scan an open Gmail message

Detect visible attachment cards and trigger Gmail’s own download controls for selected files.

02
Search real mailbox attachments

Use Gmail search syntax such as has:attachment or date/sender filters to find attachment parts.

03
Download files or ZIP

Select attachments and export individual files or a local ZIP from the Gmail attachment manager.

Read-only access. Gmail data is accessed only when you use Gmail features and with permissions you explicitly grant.

FAQ

Good to know.

Does BatchSave upload my PDFs?

No. PDF Tools are designed to process selected files locally in Chrome.

Can it download every file from every website?

No browser extension can guarantee that. Some sites block cross-origin fetching, require authentication, generate files dynamically or use unsupported redirects. BatchSave provides direct download fallback where appropriate.

How does Gmail access work?

Visible attachment scanning can use Gmail’s own page controls. Full mailbox attachment search uses the official Gmail API with explicit read-only Google authorization.

What happens when filenames are duplicated?

BatchSave does not intentionally overwrite existing files. Chrome can automatically uniquify matching filenames.

Is BatchSave Pro already on the Chrome Web Store?

Yes. Install BatchSave Pro from its official Chrome Web Store listing.

Can I manage my subscription?

Yes. Signed-in users with an active or trialing subscription can open subscription management from the extension.
